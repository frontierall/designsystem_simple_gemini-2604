# 🎨 Design System Extractor

URL 하나로 웹사이트의 디자인 시스템(색상, 폰트, CSS 변수, 스크린샷)을 자동 추출하고 시각화하는 도구입니다. GitHub Actions를 활용하여 별도의 서버 비용 없이 무료로 운영할 수 있습니다.

---

## 🚀 주요 기능 (Features)
- **자동 캡처**: 대상 사이트의 전체 화면 스크린샷 저장.
- **디자인 토큰 추출**: Computed Style 분석을 통한 색상 및 폰트 수집.
- **CSS 변수 분석**: `:root`에 정의된 테마 변수(--variable) 추출.
- **서버리스 아키텍처**: GitHub Actions가 백엔드 역할을 수행하여 데이터 자동 업데이트.
- **간편한 워크플로우**: 별도의 코딩 없이 `url.txt` 수정만으로 새로운 분석 시작.

### **v1.2.0 (Latest)** - *안정성 및 호환성 강화*
- **복잡한 사이트 대응**: 토스(`toss.im`) 등 최신 SPA 사이트를 위한 **자동 스크롤(Auto-scrolling)** 및 **User-Agent 위장** 기능 추가.

- **네트워크 대기 전략**: `networkidle0` 설정을 통해 비동기 데이터 로딩이 끝날 때까지 대기하도록 개선.

### **v1.1.0** - *사용자 경험(UX) 개선*
- **워크플로우 단순화**: 기존의 Issue 생성 방식이 번거롭다는 피드백을 반영하여, 대시보드에서 `url.txt` 편집 화면으로 즉시 이동하는 **직접 편집 링크** 버튼 도입.
- **보안 강화**: 토큰 노출 없이 GitHub의 자체 보안 환경을 활용한 트리거 방식 확정.

### **v1.0.0** - *초기 버전 출시*

- GitHub Actions와 저장소를 연동한 자동화 파이프라인 구축.
- 분석 결과를 시각화하는 웹 대시보드(`index.html`) 구현.

## 💡 프롬프트 및 응답 개선 요약 (Prompt & Response Optimization)

사용자의 초기 요청을 바탕으로, 단순한 코드 작성을 넘어 **실제 운영 가능한 수준의 솔루션**으로 다음과 같이 개선하여 응답했습니다.

1.  **환경적 제약 극복 (Static to Hybrid)**: 
    - "HTML/CSS/JS만 사용"하고 싶다는 요청과 "GitHub Pages 배포"라는 제약 사이의 모순(정적 페이지는 서버 코드를 실행 불가)을 **GitHub Actions를 연동한 하이브리드 아키텍처**로 해결책 제시.
2.  **보안 설계 (Security-First)**: 
    - 서버리스 환경에서 저장소 제어 권한(Token)을 노출하지 않기 위해, 직접적인 API 호출 대신 **GitHub의 원천 기능을 활용한 트리거 방식**을 제안하여 보안 사고 방지.
3.  **실전 대응력 강화 (Robustness)**: 
    - 단순 DOM 분석에서 멈추지 않고, 최신 웹 기술(레이지 로딩, 봇 감지)이 적용된 사이트에서도 동작하도록 **스크롤링 및 브라우저 에뮬레이션 로직**을 선제적으로 추가.

## 🛠️ 설치 및 사용법 (Setup & Usage)

1.  이 저장소를 **Fork** 하거나 생성합니다.
2.  **Settings > Actions > General**에서 `Workflow permissions`를 **Read and write permissions**로 변경합니다.
3.  **Settings > Pages**에서 `main` 브랜치를 소스로 지정하여 배포합니다.
4.  배포된 사이트에서 **[🚀 새 사이트 분석하기]** 버튼을 눌러 `url.txt`를 수정하면 분석이 시작됩니다.
